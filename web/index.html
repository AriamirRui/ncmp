网易云音乐合伙人 v2.0.0

基于 ACAne0320/ncmp 开发， 使用 Tauri + Rust 外壳 + Web 前端 + Python sidecar 架构。

  • Rust 外壳：负责窗口、进程守护与 WebView 容器
  • Web 前端：深色界面、实时日志（SSE）、任务进度与终止
  • Python sidecar：复用原有评分任务逻辑，仅监听本机 127.0.0.1
